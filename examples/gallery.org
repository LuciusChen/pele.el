#+title: Pele diagrams in Emacs
#+startup: showall

Enable =M-x pele-org-mode= to preview these diagrams below their source.
Use =M-x pele-preview= inside a block for a separate preview.
Source highlighting and =C-c '= editing use the included =pele-mode=.

* Flowchart
#+begin_src mermaid
flowchart LR
  A[开始] --> B{数据有效?}
  B -->|是| C[保存]
  B -->|否| D[修正]
  D --> B
#+end_src

* Sequence
#+begin_src mermaid
sequenceDiagram
  participant User
  participant Emacs
  participant Pele
  User->>Emacs: Edit Mermaid
  Emacs->>Pele: Render in background
  Pele-->>Emacs: SVG
  Emacs-->>User: Preview
#+end_src

* Class
#+begin_src mermaid
classDiagram
  class Diagram {
    +String source
    +render() SVG
  }
  class Preview {
    +refresh()
  }
  Diagram --> Preview
#+end_src

* Entity relationship
#+begin_src mermaid
erDiagram
  DOCUMENT ||--o{ DIAGRAM : contains
  DIAGRAM ||--o{ PREVIEW : generates
  DOCUMENT {
    string title
    string path
  }
  DIAGRAM {
    string source
    string type
  }
#+end_src
